# Pulse — Responsive Product Dashboard

A responsive product analytics dashboard built with React, Vite, Recharts, and Lucide icons. This is an independent portfolio demonstration created to showcase frontend development, dashboard UI, responsive layouts, and interactive data views.

## Features

- Responsive sidebar navigation and mobile menu
- KPI cards and revenue chart
- Sales channel breakdown
- Searchable and filterable orders table
- Pagination for order records
- Export filtered order data to CSV
- Interactive date-range selector and notification feedback
- Accessible labels and empty states

## Tech stack

- React 18
- JavaScript (ES6+)
- CSS3
- Recharts
- Lucide React
- Vite

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Build for production

```bash
npm run build
npm run preview
```

## Demo data notice

All store names, customer records, order details, and analytics displayed in this project are fictional sample data. This project is a frontend portfolio demonstration. It is not connected to a production commerce platform or backend API.
